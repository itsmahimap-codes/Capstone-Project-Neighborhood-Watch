# 🛡️ Neighborhood Watch & Incident Reporting App

A web-based application that allows residents to report and view neighborhood incidents through a centralized platform.

## 📌 Problem Statement

Neighborhood safety issues such as suspicious activities, accidents, damaged infrastructure, and other incidents may not be reported or communicated efficiently.

This application provides a simple platform where residents can report incidents, view existing reports, and track their status.

## ✨ Features

- 👤 User Registration
- 🔐 User Login
- 🚨 Report Incident
- 📋 View Incidents

## 🛠️ Technology Stack

**Frontend:** HTML, CSS, Bootstrap, JavaScript  
**Backend:** Java, Spring Boot, Spring Data JPA  
**Database:** MySQL  
**Tools:** VS Code, Maven, Git, GitHub, Thunder Client
